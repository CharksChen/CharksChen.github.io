程设 C++ 上机考试系统复习资料

发表于2026-07-07|更新于2026-07-07|计算机
|浏览量:

基于 周1–周17 全部作业梳理（周6、周11 无作业）。仅聚焦上机实操，排除笔试理论。
配套使用：模板速查手册（覆盖全部知识点）.md（详细模板）+ 三天上机冲刺复习方案.md（限时训练）。

目录

  1. 知识点梳理（按周次）
  2. 题型归纳
  3. 易错点总结
  4. 代码模板

一、知识点梳理（按周次）

每周列出核心知识点 + 对应作业，便于快速定位复习。

周1：C++ 基础过渡（命名空间 / 引用 / IO 格式化）

作业 核心知识点 要点
周1-A-课堂1 IO 流格式化 setw/left/right/fixed/setprecision/showpoint 对齐输出
周1-A-课堂2 引用传参 void Swap(int&, int&)、void Sort(int&, int&, int&)，禁用指针/全局变量
周1-课后1 命名空间 namespace Linear {}，同名函数 Linear::calculate / NonLinear::calculate
周1-课后2 返回引用 int& GetElement(int index) 返回静态数组元素引用，可作左值赋值
周1-课后3 进制转换 oct/hex/showbase/uppercase 输出八进制前缀 0、十六进制前缀 0X
周1-课后4 const 引用 + constexpr constexpr PI、void CalcCircle(const double& r, double& c, double& s)

关键记忆：引用传参避免拷贝；返回引用可作左值；const 引用防修改；IO 操纵符 left/showbase/uppercase 控制格式。

周2：字符串处理（字符分类 / 回文 / 加密 / 压缩）

作业 核心知识点 要点
周2-A-课堂1 字符分类统计 isalpha/isdigit/isspace 统计字母、数字、空格、其他
周2-A-课堂2 密码校验 长度≥8 + 含大写 + 含小写 + 含数字
周2-课后1 字符串清洗 + 回文 去非字母→转小写→判回文，输出 YES/NO
周2-课后2 凯撒加密 字母后移 SHIFT 位（循环回绕 z→c），数字替换为 *
周2-课后3 游程编码 RLE 连续相同字符压缩为 字符+次数，如 aaabbc→a3b2c
周2-课后4 多步清洗 截断(空格不计)→去数字→关键词替换，三步顺序不可颠倒

关键记忆：toupper(c)/tolower(c) 转大小写；c - '0' 数字字符转数值；stoi/to_string 互转；循环回绕用 (c - 'a' + shift) % 26 + 'a'。

周3：类与对象基础（封装 / 成员函数）

作业 核心知识点 要点
周3-课堂1 Rectangle 类 私有 length/width/style + 公有 Set/getX/getArea/print，画矩形边框
周3-课堂2 BankAccount 类 余额管理，取款不足输出提示且不扣款
周3-课后1 Time 类 24 小时制进位（秒→分→时），输出 hh:mm:ss 前导补零
周3-课后2 Fraction 分数类 GCD 约分 + 符号规范化（分母恒正，负号在分子），分母为 1 只输出分子
周3-课后3 学生成绩管理 三门课成绩 + 平均分（四舍五入 1 位）+ 优秀判断
周3-课后4 电梯状态机 当前楼层/目标楼层/状态(0停/1上/-1下)，移动中只能扩展目标

关键记忆：类声明 }; 必须有分号；私有数据 + 公有方法；输出格式严格匹配（前导零、空格分隔、换行）。

周4：类的进阶（构造/析构 / 静态成员 / this / 默认参数）

作业 核心知识点 要点
周4-课堂1 闰年判断 能被4整除为闰年；世纪年需被400整除（1900非闰，2000是闰）
周4-课堂2 Box 类 + this 默认参数构造 + this->Volume() 比较
周4-课后1 TRANSFORMER 类 构造输出 "START"、析构输出 "CLOSE"，Z 字形排版
周4-课后2 中文大写金额 数字→中文大写，"零"的处理（连续零合并、末尾零省略）
周4-课后3 ColorRGB + 静态成员 静态数据(black/white/red) + 静态函数(Distance/Mix/GetBrightness)
周4-课后4 Stack 栈类 固定数组 datas[20]，构造/析构输出提示，top() const/empty() const

关键记忆：静态成员类外定义 int Counter::count = 0;；默认参数只写在声明处；const 成员函数声明和定义都要带 const；构造优先用初始化列表。

周5：动态内存基础（new/delete / 初始化列表 / =delete）

作业 核心知识点 要点
周5-课堂1 DynamicInt new/delete 单个对象基础
周5-课堂2 IntStack 动态数组版 new[]/delete[] + = delete 禁止拷贝
周5-课后1 Student 类 const 成员 + 引用成员必须初始化列表
周5-课后2 MyString (char*版) new[strlen+1] 含 \0，越界检查
周5-课后3 IntStack 链表版 头插法，析构遍历释放所有节点
周5-课后4 Point2D const double 成员 + 初始化列表 + distance 计算

关键记忆：new 配 delete，new[] 配 delete[]；const/引用成员只能用初始化列表；链表析构要 while 循环逐个释放。

周7：拷贝构造 / 深拷贝 / mutable

作业 核心知识点 要点
周7-课堂1 Student 拷贝构造 Student(const Student& s)，score 上限 100
周7-课堂2 MyString(string版) 拷贝 验证拷贝独立性（改副本不影响原件）
周7-课堂3 Test 类 观察构造/拷贝构造/析构调用时机（值传递、返回值）
周7-课堂4 Seq 类 深拷贝 + 静态计数 total + 最长不下降子段算法
周7-课后1 Test + mutable mutable int m_count，const 函数中可修改；拷贝时 m_count 重置为 0
周7-课后2 IntArray + mutable 动态扩容(翻倍) + mutable 访问计数 + 越界返回 -1

关键记忆：拷贝构造 ClassName(const ClassName& other)；mutable 允许 const 函数修改；拷贝构造调用时机：值传参、返回值、初始化。

周8：深拷贝三件套 / 赋值运算符 / 自增自减

作业 核心知识点 要点
周8-课堂1 MyString 深拷贝 构造 + 拷贝构造 + 赋值运算符 + 析构（Rule of Three）
周8-课堂2 IntArray 深拷贝 两个重载构造 + 自赋值检查 + 三行输出验证
周8-课后1 Matrix 二维数组 二维 new[] 逐行分配 + 行优先展开反转
周8-课后2 Person 浅拷贝修正 分析 double free 原因 + 补全 operator= 深拷贝
周8-课后3 StringList operator[] 返回引用支持读写 + 深拷贝
周8-课后4 Counter 自增自减 前置 ++ 返回引用、后置 ++ 返回值(int 哑参数)

关键记忆：有 new 的类必须写 Rule of Three（拷贝构造 + 赋值运算符 + 析构）；赋值运算符固定 5 步（自赋值检查→释放旧→复制标量→分配新→逐个复制→return *this）。

周9：运算符重载进阶（[] / () / <<）

作业 核心知识点 要点
周9-课堂1 ModBuffer operator[] 取模回绕索引（负数取模处理）+ operator<< 流输出
周9-课堂2 ComparatorBuilder operator() 仿函数 + 自定义排序（禁用 std::sort）

关键记忆：operator[] 返回引用支持写；operator() 是仿函数；operator<< 必须友元/类外，返回 ostream&。

周10：单继承与派生

作业 核心知识点 要点
周10-课堂1 Shape→Rectangle→Square 多层继承 + 构造/析构链（派生→基类析构）
周10-课堂2 StringManager 派生 protected 成员 + 派生类扩展功能（reverseOrder）

关键记忆：派生类构造在初始化列表调基类构造 : Base(参数)；构造顺序基类→派生类，析构相反；protected 派生类可访问。

周12：多重继承 / 抽象类 / 多态 / 虚函数 / 单例

作业 核心知识点 要点
周12-课堂1 Cylinder 多重继承 Circle + Rectangle，表面积/体积
周12-课堂2 形状反弹模拟器 抽象类 + 纯虚函数 + 单例 ShapeManager + 固定数组管理
周12-课后1 直线与圆交点 Point 基类派生 Line/Circle + 几何距离判断交点数
周12-课后2 消息处理系统 抽象基类 + 单例 + 优先级调度（紧急每帧-2，文本每帧-1）
周12-课后3 宝可梦管理 虚函数/纯虚 + dynamic_cast + 对象进化 + using 改访问控制
周12-课后4 宝可梦对战 纯虚函数 + 属性克制 + 回合制（速度高者先攻）

关键记忆：virtual 才有多态；基类析构必须 virtual；纯虚函数 = 0；抽象类不能实例化；单例 getInstance() 返回静态局部引用。

周13：多态综合 / RTTI / 函数覆盖

作业 核心知识点 要点
周13-课堂1 动物叫声 virtual void speak() const + 菜单循环创建 + 无效选择处理
周13-课堂2 程序员计算器 继承 + 函数覆盖 + 调用计数 + 二进制转换(无前导0)
周13-课后1 物流计费 多态 + vector<Transport*> + 阶梯计费（空运>100kg加200）
周13-课后2 员工奖金 typeid(*w) == typeid(Manager) + dynamic_cast<Manager*> 访问职级
周13-课后3 进程调度 多态 + dynamic_cast<RRScheduler*> + FIFO/SJF/RR 三算法
周13-课后4 缓存替换 虚函数 + 函数重载 + FIFO/LRU/LFU 三策略 + tieRule 平局

关键记忆：typeid(*p).name() 获取类型名（编译器相关）；dynamic_cast<Derived*> 向下转型（失败返回 nullptr）；override 关键字让编译器检查覆盖正确性。

周14：抽象类综合 / final / override / 多继承接口

作业 核心知识点 要点
周14-课堂1 交通工具管理 抽象基类 + final 类/方法 + RTTI(typeid/dynamic_cast)
周14-课堂2 动物园管理 抽象类 + dynamic_cast/typeid 统计 + 固定输出顺序
周14-课堂3 电子设备管理(最难) 多继承接口(Device+Usable) + final/override + 11 命令模拟
周14-课后1 仓库货物 抽象基类 + final + typeid().name() 输出
周14-课后2 餐饮管理 抽象基类 + 多态 serve()
周14-课后3 图形接口 多继承接口(Shape+Printable) + final + 精确类型匹配(禁 name())

关键记忆：final 禁止继承/覆盖；多继承接口用逗号分隔 class X : public A, public B；RTTI 中 dynamic_cast 和 typeid 各有禁用场景，按题目要求选择。

周15：模板（函数/类/非类型参数/特化/显式实例化）

作业 核心知识点 要点
周15-课堂1 比特串解析 函数模板 + 显式实例化(template int decode<int>) + IEEE 754
周15-课堂2 Top-K 排行榜 类模板 ScoreWall<int K> + 动态维护前 K 名
周15-课后1 区间管理器 类模板 <typename T, int Limit> + 区间合并 + 淘汰最短
周15-课后2 过滤器 成员函数模板 <int Low, int High, int Window, int LevelID> + 多级级联
周15-课后3 三维张量 数组引用推导 T (&tensor)[D1][D2][D3] + 编译期维度
周15-课后4 变色龙打印 主模板 + 全特化(int/double) + 数组重载(禁右值引用)

关键记忆：模板类实现必须放 .h/.hpp（否则链接错误）；非类型模板参数 <typename T, int N>；显式实例化 template class Stack<int>;；全特化 template<> void f<int>(int){}。

周16：STL 容器入门 / LeetCode 算法

作业 核心知识点 要点
周16-课堂1 只出现一次的数字 异或解法 O(n) O(1)（LeetCode 136）
周16-课堂2 智能书架 类设计 + 增删查 + 错误信息 + 返回 const Book*
周16-课后1(选) 查找替换模式 双射匹配（LeetCode 890）
周16-课后2(选) 最大平均通过率 贪心 + priority_queue（LeetCode 1792）
周16-课后3(选) 文本编辑器 list/vector + 双栈 undo/redo
周16-课后4(选) 字谜猎手 map + 字符排序作键

关键记忆：异或性质 a^a=0, a^0=a；map 自动按 key 排序；undo/redo 新操作清空 redo 栈。

周17：STL 容器（stack/queue/priority_queue）/ 算法

作业 核心知识点 要点
周17-课堂1 最小栈 双栈：主栈 + 辅助栈 O(1) 查最小（LeetCode 155）
周17-课堂2 STL 综合 stack判回文 + count_if统计 + sort(Lambda) + accumulate求积 + pq前K大
周17-课后1 有效括号 stack<char> 括号匹配（LeetCode 20），空串合法
周17-课后2 银行排队 queue<int> FIFO 模拟
周17-课后3 急诊分诊 priority_queue<pair<int,int>> 大顶堆（severity, id）
周17-课后4 成绩分析 sort(Lambda降序) + count_if(≥60) + accumulate(注意转double)

关键记忆：priority_queue<int> 默认大顶堆；小顶堆用 priority_queue<int, vector<int>, greater<int>>；accumulate 初值类型决定结果类型（0 得 int，0.0 得 double）。

二、题型归纳

按考试常见题型分类，标注对应周次和高频程度。

题型 1：字符串处理题（★★★ 中频）

特征：读入字符串，做变换/统计/判断后输出。

子类型 典型作业 核心技巧
字符分类统计 周2-课堂1 isalpha/isdigit/isspace 逐字符扫
回文判断 周2-课后1 清洗→转小写→双指针对比
加密/编码 周2-课后2 凯撒位移 (c-'a'+shift)%26+'a'
压缩/编码 周2-课后3 游程编码 RLE，计数连续相同字符
多步清洗 周2-课后4 严格按序处理，注意"空格不计字符"等陷阱
格式化输出 周1-课后3 IO 操纵符 setw/left/showbase/uppercase

题型 2：基础类设计题（★★★★★ 最高频）

特征：设计一个类，含私有数据 + 公有方法，可能涉及构造/析构/静态成员。

子类型 典型作业 核心要点
简单封装类 周3 Rectangle/BankAccount/Time 私有数据 + getter/setter + print
数学计算类 周3 Fraction/周4 Point2D GCD化简、符号规范化、distance
构造/析构 周4 TRANSFORMER/Stack 构造析构输出时机、const 成员函数
静态成员 周4 ColorRGB 静态数据类外定义 + 静态函数
this 指针 周4 Box this->Volume() 显式调用

题型 3：动态内存 + 深拷贝题（★★★★★ 最高频丢分）

特征：类中有 new/指针成员，必须实现 Rule of Three。

子类型 典型作业 核心要点
单对象动态内存 周5 DynamicInt new/delete 配对
动态数组 周5 IntStack/周8 IntArray new[]/delete[] + 深拷贝三件套
字符串类(char*) 周5/周8 MyString new[len+1] 含 \0
链表 周5 IntStack链表版 头插 + 析构逐节点释放
二维数组 周8 Matrix 逐行 new[]，析构逐行 delete[]
浅拷贝修正 周8 Person 分析 double free + 补 operator=

题型 4：运算符重载题（★★★★ 高频）

特征：实现 + - * / < == [] () << >> ++ -- 等运算符。

子类型 典型作业 核心要点
算术运算符 周3 Fraction(隐含) operator+ 返回新对象
比较运算符 周7 Seq operator</operator== 用于排序
下标运算符 周8 StringList/周9 ModBuffer operator[] 返回引用支持读写
自增自减 周8 Counter 前置返回引用 &，后置返回值 + int 哑参数
流运算符 周9 ModBuffer operator<< 友元/类外，返回 ostream&
函数对象 周9 ComparatorBuilder operator() 仿函数 + 自定义排序

题型 5：继承多态题（★★★★★ 高频中高分）

特征：基类 + 派生类，虚函数实现多态，基类指针数组统一管理。

子类型 典型作业 核心要点
单继承基础 周10 Shape→Rectangle→Square 构造/析构链、protected 成员
多重继承 周12 Cylinder class C : public A, public B
虚函数多态 周13 Animal speak() virtual + 基类指针调用
抽象类/纯虚 周12 形状反弹/消息处理 = 0 纯虚 + 虚析构 + 派生类全实现
RTTI 周13 员工奖金/进程调度 typeid 判类型 + dynamic_cast 向下转型
综合模拟 周14 电子设备/图形接口 多继承接口 + final/override + 命令式模拟

题型 6：模板题（★★★ 中频难题）

特征：template<typename T> 或非类型模板参数。

子类型 典型作业 核心要点
函数模板 周15 比特串解析 template<typename T> T f(...) + 显式实例化
类模板 周15 Top-K/区间管理器 实现放 .hpp + <typename T, int N>
成员模板 周15 过滤器 template<int Low, int High> 成员函数模板
全特化 周15 变色龙打印 template<> void f<int>(int){}
数组引用推导 周15 三维张量 T (&arr)[D1][D2][D3] 编译期推导维度

题型 7：STL 容器/算法应用题（★★★★ 高频快拿分）

特征：用 vector/stack/queue/priority_queue/map/sort/lambda 解题。

子类型 典型作业 核心要点
栈应用 周17 最小栈/有效括号 双栈/括号匹配
队列模拟 周17 银行排队 queue FIFO
优先队列 周17 急诊分诊 priority_queue<pair<int,int>> 大顶堆
sort+lambda 周17 成绩分析/STL综合 自定义比较器排序
count_if/accumulate 周17 STL综合/成绩分析 统计+求和算法
map 应用 周16 字谜猎手 排序键 + 分组

题型 8：综合模拟题（★★★ 中频高分）

特征：命令式交互（ADD/MOVE/QUERY），多类协作，输出格式复杂。

子类型 典型作业 核心要点
状态机模拟 周3 电梯 状态转换 + 移动逻辑
管理系统 周14 电子设备/动物园 抽象类 + 命令分发 + RTTI 统计
调度算法 周13 进程调度/缓存替换 多策略 + dynamic_cast 判断

三、易错点总结

按类别归纳作业中反复出现的错误。

3.1 编译类错误（高频）

报错现象 根因 修法
expected ';' after class definition 类 } 后漏分号 加 };
undefined reference to 'Xxx::f()' 成员函数没定义 / 静态成员没类外定义 / 模板实现放了 .cpp 补定义；静态成员加 int Xxx::count = 0;；模板搬进 .h
'xxx' was not declared 忘 include / 拼写错 / 忘 using namespace std 补头文件、检查拼写
passing 'const Xxx' as this discards qualifiers const 对象调了非 const 函数 读取类函数加 const
no match for 'operator<' sort/优先队列缺比较 补 operator< 或传 lambda
cannot allocate abstract type 抽象类纯虚没实现全 派生类实现所有 =0 函数
invalid use of incomplete type 头文件互相 include 用前向声明 class X;

3.2 动态内存错误（最高频丢分）

错误现象 根因 修法
double free / 运行崩溃 浅拷贝：两个对象指向同一块内存 补深拷贝三件套（拷贝构造 + 赋值 + 析构）
内存泄漏 析构没释放 / 只释放部分 delete[] 释放数组；链表 while 循环逐个释放
赋值后原对象损坏 赋值运算符没处理自赋值 第一步 if (this == &other) return *this;
赋值后内存碎片 先 delete 再 new 导致异常 赋值运算符固定 5 步顺序（见代码模板）
二维数组释放不完整 只 delete[] 了行指针 先逐行 delete[] data[i]，再 delete[] data

3.3 边界条件处理

场景 易错点 正确做法
空栈/空队列 pop/top 空容器崩溃 先判空，返回哨兵值(-1)或输出提示
栈满 继续 push 越界 检查 topIndex == capacity，输出 “full”
数组越界 get(index) 越界访问 检查 0 <= index < size，输出提示
空字符串 回文判断空串 空串视为合法（返回 true）
分母为 0 Fraction 除零 题目保证不为 0，但仍需注意
负数取模 (-1) % 3 结果可能为负 ((index % n) + n) % n 确保非负
整数除法 accumulate(v, 0) 得 int 丢精度 初值用 0.0 得 double
浮点比较 == 比较浮点数不可靠 用 abs(a-b) < 1e-9

3.4 输出格式错误（高频低级错误）

场景 易错点 正确做法
元素间空格 末尾多/少空格 if (i+1 < n) cout << " "; 末尾不加
换行 多/少换行符 每行末尾 endl，最后一行也要换行
前导零 时间 8:5:9 应为 08:05:09 setw(2) << setfill('0')
小数位数 默认 6 位，需指定位数 fixed << setprecision(2)
大小写 十六进制字母大小写 uppercase 控制大写
前缀 八进制 0、十六进制 0X showbase 显示前缀
排序方向 升序写成降序 仔细读题"从大到小"还是"从小到大"

3.5 继承多态易错点

场景 易错点 正确做法
基类析构 非 virtual 导致派生类析构不调用 基类析构加 virtual ~Base() {}
函数覆盖 签名不一致（参数/const 差一个）不算覆盖 加 override 让编译器检查
抽象类实例化 纯虚没全实现就 new 派生类实现所有 =0 函数
对象切片 值传递/值返回导致派生部分丢失 用指针/引用传递
基类指针 delete 只调基类析构 → 内存泄漏 基类析构 virtual
dynamic_cast 向下转型失败未检查返回 nullptr if (auto p = dynamic_cast<D*>(base)) {...}

3.6 模板特有易错点

场景 易错点 正确做法
模板实现位置 放 .cpp 导致链接错误 模板类实现放 .h/.hpp
非类型参数 忘记传整型模板参数 Stack<int, 100> 而非 Stack<int>
显式实例化 题目给的 extern template 删了 不要删，按题目给的实例化列表补实现
全特化语法 template<> 漏写 template<> void f<int>(int x) {...}

3.7 审题易错点

场景 易错点 正确做法
函数签名 改了题目给的签名 签名一个字都不能改，抄下来对照
多组数据 只处理一组 while (cin >> x) 读到 EOF
读整行 cin >> s 遇空格停 getline(cin, s)，前一个 cin >> 后要 cin.ignore()
输入含空格 用 >> 读取截断 用 getline
命令分发 漏处理某个命令 逐条列出所有命令分支

附：复习优先级速查

优先级 考点 理由
P0 动态内存深拷贝 最高频丢分，编译过但运行崩
P0 继承多态/抽象类 中高分题核心，签名容易写错
P0 基础类设计 万物基础，错了后面全错
P1 运算符重载 中频，前置后置/成员友元易混
P1 STL 容器算法 最快拿分题，也可能出综合题
P1 模板 第6/7题难题来源，难度高
P2 字符串处理 早期基础题，一般不单独考

考试策略：目标 6 题稳过 > 7 题都碰。先做 A 类快题（字符串/基础类/STL），再做中等题（深拷贝/多态），最后冲模板/综合题。每题卡 10 分钟不知补什么就跳，卡 20 分钟编译不过就跳。
