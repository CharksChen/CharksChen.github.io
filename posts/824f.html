高频速查

主题 必背结论
C 与 C++ C 是面向过程；C++ 支持面向对象，核心特性有封装、继承、多态。
std 标准库名称通常在 std 命名空间中；用 std::cout 或 using namespace std;。
endl 输出换行并刷新缓冲区；\n 只换行。
输出格式 oct 八进制，dec 十进制，hex 十六进制，fixed 定点，scientific 科学计数法。
引用 引用必须初始化，初始化后不能改绑；引用不是空对象别名。
string std::string 是类类型，不是基本类型；getline 可读含空格整行。
find 找到返回位置，找不到返回 string::npos。
substr(pos, len) 从 pos 起取最多 len 个字符。
const 表示只读语义，不保证编译期常量。
constexpr 表示可用于编译期求值的常量或函数。
auto 编译期根据初始化表达式推导类型，必须能推导。
class 默认权限 class 默认 private；struct 默认 public。
const 成员函数 承诺不修改对象的非 mutable 成员，可被 const 对象调用。
构造函数 可重载，不能有返回类型，创建对象时自动调用。
析构函数 每个类最多一个，不能重载，销毁对象时自动调用。
this 指向当前对象；静态成员函数没有 this 指针。
静态成员 属于类而不是某个对象；静态成员函数只能直接访问静态成员。
new[] / delete[] 数组申请必须数组释放；new int[10] 对应 delete[] p。
堆对象 new 出来的对象不会离开作用域自动析构，必须 delete。
=default 要求编译器生成默认版本。
=delete 禁用某函数，常用于禁止拷贝或默认构造。
初始化列表 const 成员、引用成员、无默认构造的成员对象必须用初始化列表。
拷贝构造 用已有对象初始化新对象时调用，如 A b = a;。
赋值运算符 已存在对象之间赋值时调用，如 b = a;。
浅拷贝风险 指针成员只复制地址，易造成 double free、悬空指针、数据共享错误。
深拷贝 为目标对象重新分配资源并复制内容，而不是复制指针地址。
运算符重载 本质是函数；不能创造新运算符，不能改变优先级/结合性/操作数个数。
前置 ++ 通常返回 T&；后置 ++ 用 int 哑元区分，通常返回旧值副本。
多态 同一接口因对象实际类型不同表现不同行为。
运行时多态条件 基类函数为 virtual；通过基类指针或引用调用。
覆盖 Override 派生类函数与基类虚函数同名、同参数、兼容返回类型。
重载 Overload 同一作用域内函数名相同、参数列表不同，编译期决定。
对象切片 Base b = derived; 会丢掉派生类部分，多态失效。
纯虚函数 virtual void f() = 0;，含纯虚函数的类是抽象类。
抽象类 不能定义对象，但可定义指针/引用。
虚析构 基类用于多态删除时析构函数应为 virtual。
dynamic_cast 安全向下转型；指针失败返回 nullptr。
typeid 获取对象/类型的运行时类型信息；多态对象上可反映动态类型。
final 禁止类继续被继承，或禁止虚函数继续被覆盖。
函数模板 编译器按实参推导类型；模板不是函数，实例化后才生成函数。
非模板 vs 模板 参数同样完美匹配时，普通函数通常优先于函数模板。
非类型模板参数 必须是编译期常量，如整数常量、枚举、指针等；运行期变量不行。
STL vector 动态数组，连续存储，随机访问快，插入可能导致迭代器失效。
STL list 双向链表，不连续，频繁插删好，不支持随机访问。
STL deque 双端队列，两端插删高效。
STL set 元素唯一且有序，通常红黑树，查找 O(log n)。
STL unordered_set 哈希集合，平均查找 O(1)。
stack LIFO，默认底层常为 deque，访问 top()。
queue FIFO，访问 front() 和 back()。
priority_queue 默认大顶堆，top() 是最大优先级元素。
remove 算法 不真正删除容器元素，只把未删除元素前移，返回新逻辑末尾。
sort 第三参数 比较器，可用 lambda，例如 [](int a,int b){return a>b;}。
bits/stdc++.h 非标准头文件，工程项目不推荐。

第 1 周：C++ 基础、命名空间、输入输出

语言范式与面向对象

  • C 语言偏面向过程，程序由函数和过程组织。
  • C++ 兼容 C 风格过程式编程，同时支持面向对象。
  • 面向对象三大特征：封装、继承、多态。
  • “模块化”是程序设计思想，但题库中“不属于面向对象特点”的常见答案是模块化。

命名空间

  • 命名空间用于避免名字冲突。
  • 访问命名空间成员用作用域解析运算符 ::。
  • 例：Math::PI、A::flag = 0;。
  • std 是标准库常用命名空间，但不是所有标识符都属于 std。

输入输出与格式控制

  • cout << value：把值插入输出流。
  • cin >> value：从输入流提取值。
  • endl：换行并刷新缓冲区。
  • 字符输入 char a; cin >> a; 遇到输入 b 输出 b。
  • x++ 是后置自增：表达式先产生旧值，再让变量加 1。
  • 字符串字面量参与指针加法：1 + "20.26" 指向第二个字符，因此输出 0.26。
  • "12.56" 是字符串；12.56 是浮点数，连续输出无自动空格。

常见格式操纵符

操纵符 作用
oct 整数按八进制输出
dec 整数按十进制输出
hex 整数按十六进制输出
fixed 浮点按定点格式输出，默认 6 位小数
scientific 浮点按科学计数法输出
setprecision(n) 设置有效位数或小数位数，取决于是否配合 fixed

第 2 周：string、函数重载、const、constexpr、auto

std::string

  • string 是 C++ 标准库类类型。
  • 正确初始化：string s;、string s = "C++";、string s("C++");。
  • 默认构造的 string s1; 是空字符串，不是未初始化垃圾值。
  • cin >> s 只读到空白前；getline(cin, s) 可读整行。

常用成员函数

  • s.find(x)：查找子串/字符，找到返回下标，找不到返回 string::npos。
  • s.substr(pos, len)：返回从 pos 开始长度最多为 len 的子串。
  • 回文测试常用 <cctype> 中的 isalpha 判断字母，也可配合 tolower 忽略大小写。

C 标准库头文件

  • C++ 推荐使用 <cstdio>、<cmath>、<cctype>，而不是 stdio.h、math.h。
  • 这些 C 库函数通常位于 std 命名空间。

函数重载

  • 函数名相同、参数列表不同即可构成重载。
  • 返回值类型不同但参数列表完全相同，不能构成重载。
  • 重载是编译期根据实参类型和个数选择版本。

const 与 constexpr

  • const：对象不可修改，表达“只读”。
  • constexpr：表达“编译期常量/可编译期求值”。
  • C++11 中若想表达只读用 const，表达编译期常量用 constexpr。

auto

  • auto 让编译器根据初始化表达式推导类型。
  • auto it = vec.begin(); 中 it 是迭代器类型。
  • 范围 for 中 for(auto i : v) 的 i 类型取决于容器元素类型。
  • auto 必须有初始化信息，不能凭空推导。

bool

  • bool 只有 true 和 false 两个逻辑值。
  • 输出时默认可显示为 1 和 0，可用 boolalpha 显示 true/false。

第 3 周：ADT、类、对象、封装

ADT 抽象数据类型

  • ADT 全称：Abstract Data Type。
  • ADT 描述重点：数据对象、数据关系、基本操作。
  • 抽象的意义：忽略不必要细节，抓住本质属性和操作。

类与对象

  • 类是模板/类型，对象是类的实例。
  • DATE date1, date2; 中 date1 和 date2 是对象。
  • 类将数据和操作数据的函数绑定在一起，体现封装。

访问控制

关键字 含义
public 类外可访问，是对象使用者看到的接口
private 只允许类内部成员函数访问
protected 类内部和派生类可访问
  • class 默认成员权限是 private。
  • struct 默认成员权限是 public。
  • 类外访问私有成员通常通过公有 getter/setter。

成员函数

  • 类外定义成员函数用 类名::函数名，例如 void DATE::Increment()。
  • 直接写在类定义内部的成员函数通常被视为内联函数。
  • 成员函数末尾加 const：承诺不修改当前对象。
  • 对象调用公有成员函数：date1.Set(...)。

文件组织

  • 类声明、成员变量、函数原型通常放头文件，如 DATE.hpp。
  • 成员函数实现通常放 .cpp 文件。
  • .cpp 中使用类声明时需要 #include "DATE.hpp"。
  • 客户端代码指使用类接口完成任务的代码，不应依赖类内部实现细节。

第 4 周：构造函数、析构函数、this、static

构造函数

  • 构造函数与类同名，无返回类型。
  • 一个类可以有多个构造函数，靠参数列表重载。
  • 构造函数在对象创建时自动调用。
  • 若定义了有参构造，编译器不一定再自动生成无参构造。

析构函数

  • 析构函数名为 ~类名()，无返回类型、无参数。
  • 一个类最多一个析构函数，不能重载。
  • 对象生命周期结束时自动调用；堆对象必须 delete 才会调用析构。
  • 局部对象析构顺序通常与构造顺序相反。
  • static 局部对象只构造一次，程序结束时析构。

this 指针

  • this 指向当前对象。
  • this->x 常用于区分成员变量和同名形参。
  • return *this; 常用于链式调用。
  • 静态成员函数没有 this 指针，不能直接访问非静态成员。

静态成员

  • 静态成员变量属于类，所有对象共享一份。
  • 静态成员变量通常需要在类外定义和初始化，如 int A::count = 0;。
  • 可用 A::count 访问公有静态成员。
  • 静态成员函数可在无对象时调用，但只能直接访问静态成员。

第 5 周：内存布局、new/delete、默认与删除函数、初始化列表

程序内存布局

区域 存放内容
代码区 程序指令
全局/静态区 全局变量、静态变量
常量区 字符串字面量等只读常量
栈区 局部变量、函数调用信息，自动管理
堆区 new 动态分配的对象，手动管理

字符串字面量与字符数组

  • char *s1 = "Literal"; 在现代 C++ 中不安全，字符串字面量不可修改。
  • char s2[] = "Literal"; 会创建可修改的字符数组副本。

new 与 delete

  • new T：分配一个对象，返回 T*。
  • new T[n]：分配对象数组，返回首元素指针。
  • delete p：释放单个对象。
  • delete[] p：释放数组对象。
  • new int[5]{1,3,5} 剩余元素会值初始化为 0，所以输出 1 3 5 0 0。
  • new[] 配 delete 或 new 配 delete[] 都是错误用法，可能未定义行为。

指针与对象

  • 对象指针访问成员用 ->，如 p->show()。
  • Text* p = &str; 表示 p 指向栈上已有对象 str。
  • 堆上对象不会因指针变量离开作用域自动析构。

野指针与内存泄漏

  • 野指针：指向无效内存的指针，如释放后继续使用。
  • 释放后建议置为 nullptr。
  • 内存泄漏：动态分配的内存失去释放机会，如覆盖原指针或忘记 delete。

=default 与 =delete

  • A() = default; 显式要求编译器生成默认构造。
  • A(const A&) = delete; 禁用拷贝构造。
  • A& operator=(const A&) = delete; 禁用拷贝赋值。
  • 删除函数可以参与重载决议，但一旦被选中就编译错误。

成员初始化列表

  • 语法：A(int v) : x(v), y(0) {}。
  • 初始化列表发生在构造函数体执行前。
  • 必须用初始化列表的成员：const 成员、引用成员、没有默认构造函数的成员对象。
  • 成员实际初始化顺序由成员在类中声明顺序决定，不由初始化列表书写顺序决定。

第 7 周：对象存储、const 指针、拷贝构造、浅拷贝

对象存储与释放

  • 普通局部对象在栈上，作用域结束自动析构。
  • new 创建对象在堆上，必须手动 delete。
  • int* q = p; delete p; 后 q 也悬空，因为二者指向同一块内存。
  • new A[3] 要求 A 有可调用的默认构造函数。

const 指针辨析

写法 含义
const int* p 指向常量的指针，不能通过 p 改值，但 p 可改指向
int const* p 同 const int* p
int* const p 常量指针，p 不可改指向，但可通过 p 改值
const int* const p 指向常量的常量指针

对象内存组成

  • 普通类对象主要包含非静态数据成员。
  • 成员函数代码不存放在每个对象中。
  • 静态成员变量不属于单个对象，不计入普通对象的实例数据。

拷贝构造函数

  • 形式：A(const A& other)。
  • 用已有对象初始化新对象时调用。
  • 函数按值传参会调用拷贝构造。
  • 函数返回对象、用对象初始化对象也可能涉及拷贝构造，现代编译器可能优化。

赋值与初始化

  • A b = a;：初始化，调用拷贝构造。
  • b = a;：赋值，调用赋值运算符。
  • A& operator=(const A&) 不是拷贝构造。

浅拷贝问题

  • 默认拷贝构造和默认赋值运算符通常做成员逐个复制。
  • 对指针成员来说，这只是复制地址。
  • 若两个对象拥有同一块堆内存，析构时会重复释放，引发严重错误。
  • 有资源所有权的类通常需要自定义析构、拷贝构造、拷贝赋值。

第 8 周：运算符重载、赋值运算符、深拷贝

运算符重载基本原则

  • 运算符重载本质是函数重载。
  • 不能创造新运算符。
  • 不能改变运算符优先级、结合性、操作数个数。
  • 至少一个操作数通常应为用户自定义类型。
  • 可以重载为成员函数，也可以重载为非成员/友元函数。

成员函数形式

  • 双目成员运算符中，左操作数通过 this 隐式传递。
  • a + b 若为成员函数，等价于 a.operator+(b)。
  • 成员函数末尾加 const，表示运算不修改左操作数。
  • const Integer& 参数可避免复制并保护实参不被修改。

何时用非成员/友元

  • 当左操作数不是本类对象时，常用非成员函数。
  • 典型例子：cout << obj，左操作数是 ostream。
  • 输入输出运算符 <<、>> 通常重载为友元或普通非成员函数。

自增运算符

表达式 典型声明 返回
前置 ++a T& operator++(); 修改后对象引用
后置 a++ T operator++(int); 修改前对象副本
  • 后置版本的 int 是哑元参数，只用于区分前置/后置。
  • 前置通常更高效，因为不需要保存旧副本。

赋值运算符与深拷贝

  • 默认赋值运算符对指针成员是浅拷贝。
  • 自定义赋值运算符通常返回 T&，支持链式赋值 a = b = c。
  • 第一件事通常检查自赋值：if (this == &other) return *this;。
  • 深拷贝常见顺序：自赋值检查、释放旧资源、分配新资源、复制内容、返回 *this。
  • 更稳的写法可用 copy-and-swap，但题库重点是上述基本流程。

第 12-13 周：继承、多态、虚函数、覆盖与重载

多态与继承

  • 继承允许复用已有代码。
  • 多态表示同一接口在不同对象上表现出不同行为。
  • C++ 多态常分为编译期多态和运行时多态。
  • 函数重载、模板属于编译期多态；虚函数属于运行时多态。

虚函数与动态绑定

  • 基类成员函数加 virtual 后，通过基类指针/引用调用时发生动态绑定。
  • 动态绑定依赖对象的动态类型，常通过虚函数表/虚函数指针实现。
  • 非虚函数调用按静态类型决定。
  • 构造函数不能是虚函数。
  • 静态成员函数不能是虚函数。

运行时多态条件

  1. 基类中被调用函数声明为 virtual。
  2. 派生类覆盖该虚函数。
  3. 通过基类指针或引用调用。

重载、覆盖、隐藏

概念 判定
重载 Overload 同一作用域，函数名相同，参数列表不同
覆盖 Override 派生类重写基类虚函数，函数签名匹配
隐藏 Hide 派生类声明同名函数，可能隐藏基类同名函数，即使参数不同
  • override 用于显式检查派生类函数是否真的覆盖基类虚函数。
  • 参数列表不同不是覆盖，可能导致隐藏。
  • 返回类型不同通常不能单独构成重载。

静态类型与动态类型

  • 静态类型：变量声明时的类型，编译期已知。
  • 动态类型：对象运行时实际类型。
  • Base* p = new Derived; 中 p 静态类型是 Base*，所指对象动态类型是 Derived。
  • 虚函数调用取决于动态类型。

对象切片

  • Base b = d; 会只保留 Base 子对象，派生类部分被切掉。
  • 对象切片后用 b 调虚函数，也只能表现为基类对象。
  • 避免切片：使用基类指针或引用。

第 14 周：抽象类、纯虚函数、RTTI、final、虚析构

纯虚函数与抽象类

  • 纯虚函数声明：virtual void f() = 0;。
  • 含有至少一个纯虚函数的类是抽象类。
  • 抽象类不能实例化对象。
  • 抽象类可以声明指针和引用。
  • 派生类如果没有实现全部纯虚函数，仍然是抽象类。

接口风格抽象类

  • 通常只包含纯虚函数和虚析构函数。
  • 用于规定一组行为接口。
  • 多重继承接口类在 C++ 中常见且可用。

虚析构函数

  • 若可能通过基类指针删除派生类对象，基类析构函数必须是虚析构。
  • 否则 delete basePtr; 可能只调用基类析构，派生类资源泄漏。
  • 抽象基类也应提供虚析构函数。

RTTI

  • RTTI：Run-Time Type Information，运行时类型信息。
  • 用于在运行时识别对象真实类型。
  • typeid(x) 获取类型信息。
  • dynamic_cast 做安全类型转换，尤其是向下转换。
  • dynamic_cast<Derived*>(basePtr) 失败返回 nullptr。
  • dynamic_cast<Derived&>(baseRef) 失败抛出 std::bad_cast。
  • 使用 dynamic_cast 的类层次通常需要有虚函数，即多态类型。

final

  • class B final : public A {}：禁止继续继承 B。
  • void f() final;：禁止派生类继续覆盖 f。
  • final 只能用于虚函数覆盖场景；非虚函数不能标 final。

第 15 周：模板、特化、非类型模板参数

泛型编程与模板

  • 模板让代码独立于具体类型，提高复用性。
  • 函数模板不是函数，类模板不是类；实例化后才生成具体函数/类。
  • 模板通常放在头文件中，因为编译器实例化时需要看到定义。

函数模板

  • 示例：template <typename T> T foo(T a, T b);
  • 同一个模板参数 T 通常需要由实参推导为同一类型。
  • foo(1, 2.0) 在不考虑隐式转换时会推导冲突。
  • 显式实例化声明示例：template void swap<int>(int&, int&);。

模板与重载决议

  • 函数模板可以重载。
  • 普通函数与模板函数同名且都完美匹配时，普通函数通常优先。
  • 更特化的模板匹配优先于更泛化模板。
  • 全特化语法：template <> void print<int>(int x) {...}。

类模板

  • 类模板示例：template <typename T, int N> class Array {...};
  • Array<int, 10> 和 Array<int, 20> 是不同类型。

非类型模板参数

  • 非类型模板参数必须是编译期常量。
  • Buffer<n> 中若 n 是运行期输入变量，会编译错误。
  • C++11 常见可用类型包括整数、枚举、指针、引用等；浮点类型不能作为 C++11 非类型模板参数。

数组引用模板

  • template <typename T, int N> void getLength(T (&arr)[N]); 可推导数组长度。
  • 若写成 T arr[N]，函数形参会退化为指针，无法可靠推导长度。
  • 二维数组引用：T (&matrix)[R][C] 可推导行列数。

typename

  • 在模板中引用依赖类型时常需要 typename。
  • 例如 typename T::value_type x; 告诉编译器这是类型名。

第 16-17 周：STL、容器适配器、迭代器、算法

STL 组成

  • 容器：存储数据。
  • 迭代器：连接容器和算法。
  • 算法：对迭代器范围执行操作。
  • 函数对象、适配器、分配器也是 STL 体系的一部分。

常见容器

容器 特点 适用场景
array 固定大小，连续存储，不动态分配 编译期固定长度数组
vector 动态数组，连续存储，随机访问快 高频随机访问、尾部插入
deque 分段连续，双端插删快 队列、双端操作
list 双向链表，不连续 频繁任意位置插删，不要求随机访问
forward_list 单向链表 更省空间的单向遍历
set 有序唯一集合 需要排序和唯一性
map 有序键值对 按键查找，键唯一
unordered_set 哈希唯一集合 平均 O(1) 查找

容器适配器

  • stack、queue、priority_queue 属于容器适配器。
  • 适配器在底层容器之上限制接口，提供特定访问方式。
适配器 访问规则 常用操作 默认底层
stack 后进先出 LIFO push、pop、top deque
queue 先进先出 FIFO push、pop、front、back deque
priority_queue 最高优先级先出 push、pop、top vector
  • priority_queue 默认是大顶堆，top() 通常返回最大元素。
  • priority_queue::pop() 本质上涉及堆调整，常联想到 pop_heap。

迭代器

迭代器 能力
输入迭代器 读取并向前移动
输出迭代器 写入并向前移动
前向迭代器 可多次向前遍历
双向迭代器 支持前进和后退
随机访问迭代器 支持 it+n、it[n]、大小比较
  • vector、deque、array 通常提供随机访问迭代器。
  • list 提供双向迭代器。
  • forward_list 提供前向迭代器，典型操作是 ++it。

迭代器失效

  • vector 插入元素可能重新分配内存，导致迭代器、指针、引用失效。
  • 遍历时调用 erase(it) 后，原 it 失效。
  • 正确写法通常是 it = v.erase(it);，不要再对旧 it++。

常用算法

  • copy(first, last, dest)：复制范围元素。
  • reverse(first, last)：反转范围。
  • generate(first, last, gen)：用生成器填充范围。
  • remove(first, last, value)：把不等于 value 的元素前移，返回新逻辑末尾，不改变容器实际大小。
  • 真正删除常配合 erase-remove idiom：v.erase(remove(v.begin(), v.end(), x), v.end());。
  • sort(first, last, comp)：排序，第三参数是比较器。
  • Lambda 比较器：[](int a, int b) { return a > b; } 表示降序。

范围 for

  • C++11 范围 for 可用于数组、STL 容器、以及提供 begin/end 的对象。
  • for (auto x : v) 拷贝元素。
  • for (auto& x : v) 可修改元素且避免复制。
  • for (const auto& x : v) 只读且避免复制。

工程习惯

  • 不推荐 #include <bits/stdc++.h>：它不是 C++ 标准头文件，可移植性差，编译依赖重。
  • 应按需包含标准头：<vector>、<algorithm>、<queue>、<stack> 等。

C++ 基础与输入输出

  • 语言范式：C 是面向过程；C++ 支持过程式、面向对象和泛型编程；面向对象三特征是封装、继承、多态。
  • C++ 相比 C 的新增方向：类与对象、引用、函数重载、命名空间、流式 I/O、模板、STL、异常等；不是所有 C 语法都属于 C++ 新增。
  • 命名空间：解决名字冲突；访问成员用 ::；std::cout、std::cin、std::endl 都是常见标准库名字。
  • 输入输出运算符：<< 是输出流插入，>> 是输入流提取；连续输出不会自动加空格。
  • 操纵符：oct、dec、hex 控制整数进制；fixed 定点；scientific 科学计数法；endl 换行并刷新。
  • 表达式求值：后置 x++ 先用旧值再自增；位移运算 cout << (cout << cout) 这类题要先区分变量名和 std::cout。
  • 字符串字面量指针偏移：1 + "20.26" 指向下标 1 的字符，输出从那里开始的后缀。
  • 引用：必须初始化，之后不能改绑；引用常作为函数参数避免复制，也可用于返回当前对象。

标准库字符串、C 库、类型推导

  • std::string：类类型，默认构造为空串；可由字符串字面量初始化；不是 C 风格字符数组。
  • getline(cin, s)：读取整行，适合包含空格的句子；cin >> s 遇空白停止。
  • string::find：可查字符或子串，返回位置；失败返回 string::npos。
  • string::substr(pos, len)：从 pos 开始取最多 len 个字符。
  • <cctype>：isalpha 判断字母，tolower 可用于忽略大小写的回文判断。
  • C 库头文件：C++ 推荐 <cstdio>、<cmath>、<cctype>，函数通常放入 std。
  • 函数重载：同名函数参数列表不同；仅返回值不同不能重载；重载决议在编译期完成。
  • const：只读语义；constexpr：编译期常量/可编译期求值；二者不能混为一谈。
  • auto：根据初始化表达式推导类型；范围 for 中 auto i 取决于元素类型；缺少初始化无法推导。
  • bool：逻辑值 true/false；默认输出常为 1/0，可用 boolalpha。

ADT、类、对象、封装

  • ADT：Abstract Data Type，描述数据对象、数据关系和基本操作，强调“做什么”而非“怎么做”。
  • 抽象：保留本质属性和操作，忽略无关细节。
  • 类与对象：类是类型模板，对象是实例；DATE date1, date2; 声明两个对象。
  • class 与 struct：二者都可定义类；默认访问权限分别是 private 和 public。
  • 访问控制：public 是接口；private 隐藏实现；protected 允许派生类访问。
  • 封装：数据和操作绑定，并隐藏内部实现；类外通常通过 getter/setter 访问私有成员。
  • 成员函数类外定义：使用 ClassName::func；类内直接定义的成员函数通常视为内联（inline）。
  • const 成员函数：末尾 const 表示不修改对象，可被 const 对象调用。
  • 文件组织：类声明放 .hpp/.h，实现放 .cpp，实现文件包含对应头文件；客户端代码只依赖接口。

构造、析构、对象生命周期

  • 构造函数：与类同名、无返回类型、创建对象时自动调用；可重载。
  • 默认构造：若声明了有参构造，编译器可能不再生成默认构造。
  • 析构函数：~ClassName()，无参数、无返回类型、不能重载、每类最多一个。
  • 析构顺序：局部对象通常按构造相反顺序析构；静态局部对象只构造一次，程序结束析构。
  • 堆对象生命周期：new 创建后不会自动析构，必须 delete；对象指针离开作用域不等于对象销毁。
  • 成员初始化列表：先于构造函数体执行；实际顺序按成员声明顺序；const 成员、引用成员、无默认构造的成员对象必须使用。
  • this：当前对象指针；用于区分同名形参和成员；return *this 支持链式调用。
  • 静态成员：属于类共享一份；静态成员变量通常类外定义；静态成员函数没有 this，不能直接访问非静态成员。

内存、指针、资源管理

  • 内存区域：代码区、全局/静态区、常量区、栈区、堆区；局部对象常在栈，动态对象在堆。
  • 字符串字面量：通常不可修改；char s[] = "Literal" 是可修改数组副本。
  • new T 对应 delete p；new T[n] 对应 delete[] p；混用是未定义行为。
  • 数组值初始化：new int[5]{1,3,5} 后两个元素为 0。
  • 对象指针访问：p->member 等价于 (*p).member。
  • 野指针：释放后继续保存旧地址；释放后置 nullptr 可降低误用风险。
  • 内存泄漏：动态资源失去释放机会；常见于忘记 delete 或覆盖唯一指针。
  • =default：显式使用编译器默认实现；=delete：禁用函数，常禁用默认构造、拷贝构造、拷贝赋值。

拷贝控制与深浅拷贝

  • 默认拷贝构造和默认赋值通常逐成员复制；普通成员没问题，指针成员会浅拷贝地址。
  • 拷贝构造：用已有对象初始化新对象，如 A b = a;、按值传参。
  • 赋值运算符：已有对象之间赋值，如 b = a;。
  • 浅拷贝风险：两个对象共享同一堆资源，可能 double free、悬空指针、数据被互相影响。
  • 深拷贝：目标对象拥有独立资源，复制内容而不是复制地址。
  • 资源管理“三件套”：析构函数、拷贝构造函数、拷贝赋值运算符；有指针所有权时尤其重要。
  • 自赋值检查：if (this == &other) return *this;。
  • 深拷贝赋值顺序：检查自赋值，释放旧资源，分配新资源，复制内容，返回 *this。
  • const int* p：不能通过 p 改值；int* const p：p 不能改指向；const int* const p 两者都限制。

运算符重载

  • 本质：运算符重载是函数重载；不能创造新运算符，不能改优先级、结合性、操作数个数。
  • 成员形式：左操作数是 this；a + b 可等价于 a.operator+(b)。
  • 参数设计：常用 const T& 避免复制并保护实参；不修改当前对象的运算符成员函数末尾加 const。
  • 非成员/友元：左操作数不是本类对象时常用，例如 cout << obj。
  • 前置自增：T& operator++()，修改后返回自身引用。
  • 后置自增：T operator++(int)，int 是哑元，返回修改前副本。
  • 赋值运算符返回 T&，支持链式赋值 a = b = c。
  • 复合赋值可复用已有 operator+，但要注意效率和自赋值。

继承、多态、虚函数

  • 继承：复用已有代码，建立 “is-a” 类型关系。
  • 多态：同一接口对不同动态类型表现不同行为；重载/模板是编译期多态，虚函数是运行时多态。
  • 虚函数：基类函数加 virtual 后，通过基类指针/引用调用时可动态绑定。
  • 动态绑定实现：通常通过虚函数表和虚函数指针；题目只需知道按运行时实际对象类型选择函数。
  • 运行时多态必要条件：基类虚函数、派生类覆盖、通过基类指针或引用调用。
  • 非虚函数：按静态类型绑定；基类指针调用非虚函数不会自动调派生类版本。
  • 覆盖：派生类函数与基类虚函数同名、同参数、兼容返回；override 可让编译器检查。
  • 重载：同一作用域同名不同参数；与是否虚函数无关。
  • 隐藏：派生类声明同名函数会隐藏基类同名函数，即使参数不同。
  • 静态类型：变量声明类型；动态类型：运行时真实对象类型。
  • 对象切片：Base b = d; 只保留基类子对象，派生类部分丢失，多态失效。

抽象类、RTTI、final、虚析构

  • 纯虚函数：virtual void f() = 0;；含纯虚函数的类是抽象类。
  • 抽象类限制：不能创建对象，能声明指针和引用；派生类未实现全部纯虚函数仍是抽象类。
  • 接口风格抽象类：主要由纯虚函数和虚析构组成；多重继承接口类是常见做法。
  • 虚析构：基类用于多态删除时必须虚析构，否则通过基类指针 delete 派生对象可能资源泄漏。
  • RTTI：运行时类型信息，用于识别对象真实类型。
  • dynamic_cast：安全向下转型；目标为指针失败返回 nullptr，目标为引用失败抛 std::bad_cast。
  • typeid：获取类型信息；对多态对象可反映动态类型。
  • final 类：禁止继承；final 虚函数：禁止后续覆盖；非虚函数不能作为最终覆盖。

模板与泛型编程

  • 模板目标：让代码独立于具体类型，提高复用。
  • 函数模板/类模板本身不是具体函数/类，实例化后才生成具体实体。
  • 模板定义通常放头文件，因为实例化时编译器必须看到完整定义。
  • 函数模板推导：同一模板参数需要推导成一致类型；foo(1, 2.0) 可能冲突。
  • 普通函数优先：非模板函数和模板函数都完美匹配时，普通函数通常优先。
  • 模板特化：template <> ... 为特定类型提供专门实现。
  • 类模板外部实现：需要写 template <typename T> 和 ClassName<T>::。
  • 非类型模板参数：必须是编译期常量；运行期变量不能作为模板实参；C++11 下浮点类型不能作为非类型模板参数。
  • 数组长度推导：T (&arr)[N] 保留长度；T arr[N] 退化为指针。
  • 二维数组模板：T (&matrix)[R][C] 可推导行列。
  • typename：在模板中说明依赖名是类型，如 typename T::value_type。

STL 容器、迭代器、算法

  • STL 组件：容器、迭代器、算法、函数对象、适配器、分配器。
  • array：固定大小、连续存储、不动态分配。
  • vector：动态数组、连续存储、随机访问快，插入可能导致迭代器失效。
  • deque：双端队列，两端插删高效，常作 stack 和 queue 默认底层。
  • list：双向链表，不连续，插删方便，不支持随机访问。
  • forward_list：单向链表，迭代器典型支持 ++it。
  • set：唯一且有序，通常 O(log n) 查找。
  • unordered_set：哈希集合，平均 O(1) 查找。
  • map::find(k)：找不到返回 m.end()。
  • 容器适配器：stack、queue、priority_queue；适配器限制底层容器接口形成特定访问规则。
  • stack：LIFO，top() 查看栈顶；底层需支持 back/push_back/pop_back。
  • queue：FIFO，front() 查看队首，back() 查看队尾。
  • priority_queue：默认大顶堆，top() 最大；pop() 会进行堆调整。
  • 迭代器类别：输入、输出、前向、双向、随机访问；vector/deque/array 常提供随机访问迭代器。
  • 范围 for：适用于数组、STL 容器和提供 begin/end 的对象；auto& 可避免复制并修改元素。
  • 迭代器失效：erase(it) 后原 it 失效；正确模式是 it = container.erase(it)。
  • copy：复制区间；reverse：反转区间；generate：用生成器填充。
  • remove：移动未删除元素并返回新逻辑末尾，不改变容器大小；真正删除要配合 erase。
  • sort：第三参数是比较器；lambda [](int a, int b){ return a > b; } 表示降序。
  • #include <bits/stdc++.h>：非标准、可移植性差，工程中不推荐。

考前最后 10 分钟

  1. 看到 virtual，先判断是否通过基类指针/引用调用。
  2. 看到指针成员，默认想到“三件套”：析构、拷贝构造、拷贝赋值。
  3. 看到 new[]，答案多半盯住 delete[]。
  4. 看到 const int* p，读成“不能通过 p 改值”；看到 int* const p，读成“p 不能改指向”。
  5. 看到模板数组长度，只有引用形参 T (&arr)[N] 才能保留数组长度。
  6. 看到 STL 删除元素，remove 只是移动，真正删要 erase。
