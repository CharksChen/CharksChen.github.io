1. 头文件：该 include 什么

容易忘的头文件对照：

你要用什么 必须 include 忘了会怎样
accumulate <numeric> 'accumulate' was not declared
sqrt, pow <cmath> 'sqrt' was not declared
isalpha, isdigit, toupper <cctype> 'isalpha' was not declared
abs(整数) <cstdlib> 或 <cmath> 'abs' was not declared
setw, setprecision <iomanip> 'setw' was not declared
INT_MAX <climits> 'INT_MAX' was not declared
greater<int> <functional> 'greater' was not declared
stoi, to_string <string> (已含) 一般不会忘
strlen 等C函数 <cstring> 'strlen' was not declared

建议：考试时一股脑全 include，不省那几行。宁可多 include 也不报错。

21. 编译错误大全：报错→原因→修法

30+ 条常见编译错误速查。

类与成员

报错信息 原因 修法
expected ';' after class definition 或 expected ';' at end of class 类 } 后漏分号 加 };
expected ';' before 某标识符 上一行漏分号 在上一行末加 ;
undefined reference to 'Xxx::func()' 成员函数声明了但没定义 在 .cpp 补 Xxx::func() 定义
undefined reference to 'Xxx::count' 静态成员没类外定义 .cpp 加 int Xxx::count = 0;
no matching function for call to 'Xxx::func()' 函数签名不匹配 检查参数个数/类型/const
cannot declare member function to have static linkage 静态函数定义加了 static 定义时不加 static
'func' is not a member of 'Xxx' 函数名拼错或忘加 Xxx:: 加 Xxx:: 或修正拼写
redefinition of 'Xxx::func()' 函数定义了两次 删除重复定义

const 相关

报错信息 原因 修法
passing 'const Xxx' as 'this' argument discards qualifiers const 对象调了非 const 函数 函数声明加 const
assignment of member 'Xxx::data' in read-only object const 函数里修改了成员 去掉 const 或用 mutable
no matching function for call (const 版) 声明有 const 定义没 const 定义也加 const

include 与作用域

报错信息 原因 修法
'xxx' was not declared in this scope 忘 include / 拼写错 / 没 using namespace 补 include / 检查拼写 / 加 using namespace std;
'cout' was not declared 忘 #include <iostream> 或 using namespace std 补上
'string' was not declared 忘 #include <string> 或 using namespace std 补上
'accumulate' was not declared 忘 #include <numeric> 补上
'sqrt' was not declared 忘 #include <cmath> 补上
'setw' was not declared 忘 #include <iomanip> 补上
redefinition of 'class Xxx' 头文件没保护 / 重复 include 加 #ifndef 或 #pragma once

继承与多态

报错信息 原因 修法
cannot allocate an object of abstract type 'Xxx' 纯虚函数没全实现 派生类实现所有 = 0
marked 'override' but does not override any virtual function 签名不一致 检查参数/const/返回值是否和基类一致
no matching function for call to 'Xxx::Xxx()' 派生类需要默认构造但没提供 加默认构造函数
invalid use of incomplete type 'class Xxx' 两个头文件互相 include 用前向声明 class Xxx;
request for member 'func' is ambiguous 多重继承同名冲突 加 Base::func() 显式指定
cannot dynamic_cast ... (source type is not polymorphic) 基类没有 virtual 函数 基类加至少一个 virtual

模板

报错信息 原因 修法
undefined reference to 'Stack<int>::push(int const&) 模板实现放 .cpp 搬到 .h/.hpp
expected ';' before '<' token 类外定义忘 template<typename T> 加前缀
too few template-parameter-lists 类外定义忘 <T> Stack<T>::func
no matching function for call to 'max(T, T)' 类型不一致 max<int>(3, 3.14) 显式指定
expected primary-expression before '>' token 模板参数不匹配 检查参数类型/个数

运算符重载

报错信息 原因 修法
no match for 'operator<<' 没重载 << 或不是友元 加 friend ostream& operator<<
no match for 'operator<' sort 缺比较 补 operator< 或传 lambda
candidate is: Xxx operator++() 前置后置搞混 后置加 int 哑参数
cannot bind 'std::ostream' lvalue to 'const std::basic_ostream<char>&' << 返回类型错 返回 ostream& 不是 void

运行时错误

现象 原因 修法
Segmentation fault / 段错误 空指针/越界/野指针访问 检查指针和下标
double free / 堆损坏 浅拷贝导致重复释放 补深拷贝三件套
程序卡死无输出 死循环 / 等待输入 检查循环条件和输入
输出后崩 析构时释放已释放内存 检查析构和赋值运算符
结果全 0 忘记读输入 / 初始化 检查 cin 和初始化

链接错误

报错信息 原因 修法
undefined reference to 'WinMain' 没有 main 函数 加 int main()
multiple definition of 'xxx' 全局变量/函数定义在头文件中 只声明在 .h，定义放 .cpp
cannot find -lxxx 缺库 考试一般不会遇到

22. 考前必背 30 条语法口诀

考前最后看一遍这 30 条，能避免 90% 的编译错误。

  1. 类声明后必须有分号：class A { ... }; ← 分号！
  2. 成员函数定义加 ClassName::：int A::getX() const { ... }
  3. const 两边一致：声明和定义的 const 必须完全相同
  4. 默认参数只写声明：.h 写 = 0，.cpp 不写
  5. 静态成员类外定义：int A::count = 0; 不能忘
  6. 静态函数定义不加 static：int A::getCount() { ... }
  7. const/引用成员用初始化列表：A(int x) : id(x), ref(r) {}
  8. new 配 delete，new[] 配 delete[]
  9. 有指针成员写三件套：拷贝构造 + 赋值运算符 + 析构
  10. 赋值运算符 5 步：自检→释放→复制标量→分配→逐个复制→return *this
  11. 基类析构加 virtual：virtual ~Base() {}
  12. override 让编译器检查：void func() override
  13. 抽象类纯虚全实现才能实例化
  14. 多态用指针/引用，值传递会对象切片
  15. dynamic_cast 要有多态（基类至少一个 virtual）
  16. << 重载必须友元，返回 ostream&
  17. 后置 ++ 加 int 哑参数：Counter operator++(int)
  18. 模板实现放 .h/.hpp，不能放 .cpp
  19. 模板类外定义带 template<typename T> 和 <T>
  20. 头文件加保护：#ifndef 或 #pragma once
  21. getline 前要 ignore：cin >> n; cin.ignore(); getline(cin, s);
  22. accumulate 初值 0.0 得 double，0 得 int
  23. priority_queue 小顶堆：priority_queue<int, vector<int>, greater<int>>
  24. map 自动按 key 排序，set 自动去重
  25. 元素间空格末尾不加：if (i+1 < n) cout << " ";
  26. 前导零用 setw+setfill：setfill('0') << setw(2) << 8
  27. stoi/to_string 在 <string> 里
  28. accumulate 在 <numeric> 里（不是 <algorithm>）
  29. toupper/tolower 返回值不改原字符，要 c = toupper(c)
  30. 万能开头一次 include 全：iostream/string/vector/algorithm/queue/stack/map/set/cmath/iomanip/numeric/cctype

使用建议：考前把第 22 节（30 条口诀）背熟，考试中遇到编译错误翻第 21 节对照表，写代码时不确定语法翻对应章节。
